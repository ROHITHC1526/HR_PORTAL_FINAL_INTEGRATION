# Brightcone HR UI

Frontend application for Brightcone HR Portal.

## Architecture & Modules

- **App Rail & Shell**: Unified switcher with dynamic sidebar navigation.
- **Recruit & ATS**: Candidates, job requirements, interview stages, offers, and internships.
- **People & Directory**: Employee directory, profile, documents, and leave administration.
- **Payroll & Expenses**: 5-step payroll run wizard, Indian salary structures with PF/PT/TDS calculation, salary revisions, payslips, PF/ESI & Form 24Q compliance, and employee/office expenses.
- **Engagement**: Company news feed, announcements, and helpdesk queue.

## Getting Started

```bash
npm install
npm run dev
```
