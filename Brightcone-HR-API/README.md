# Brightcone HR API

Full-Stack Rust/Loco backend service for Brightcone HR Portal, providing Recruitment, Employee Self-Service, and the Payroll & Expenses platform.

## Features & Modules

- **Recruitment & Onboarding**: Candidates, job requisitions, interview stages, offers, and internships.
- **Employee Self-Service**: Attendance punch, regularisation, leave applications, documents, and goals.
- **Payroll & Salary Management**: Statutory Indian salary calculation (PF, PT, TDS, HRA), salary structures, revision approvals, and 5-step payroll run wizard.
- **Expense Claims & Office Invoicing**: Employee claims lifecycle and GST office expense tracking.

## Local Development

Requirements: Rust toolchain, PostgreSQL (Port 5433), Node.js for UI.

```powershell
cargo loco start
```
